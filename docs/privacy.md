# SnipDock Privacy

SnipDock is local-first. Clipboard text, library items, templates, projects, tags, settings, and backups stay on the device unless the user explicitly exports data.

Private and sensitive records are marked for redaction and protected workflows. Private records cannot leave the local export boundary.

Normal production launches contact GitHub Releases over HTTPS to check for and download signed SnipDock updates. Hidden Windows sign-in launches do not check for updates. Update requests contain application version and platform metadata, never clipboard text, library content, templates, settings, or backups.
