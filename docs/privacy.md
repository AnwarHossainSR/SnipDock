# SnipDock Privacy

SnipDock is local-first. Clipboard text, snippets, templates, projects, tags, settings, backups, activity, AI previews, and sync state stay on the device unless the user explicitly exports data or enables a future provider.

AI is opt-in per action. The review panel shows outbound content first and refuses private items. The current provider boundary is fake and makes no network call.

Sync is disabled by default. The current sync status panel reports local state only and makes no network call.

Private and sensitive records are marked for redaction and protected workflows. Full encrypted-at-rest verification belongs to the final security pass before release.
