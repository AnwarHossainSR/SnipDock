# Security Policy

## Supported Versions

SnipDock is pre-release software. Only the latest commit on the default branch receives security fixes until the first stable release.

## Reporting a Vulnerability

Do not report vulnerabilities through public issues.

Use GitHub's **Report a vulnerability** option in the repository Security tab to submit a private security advisory. Include affected version or commit, reproduction steps, impact, and any suggested mitigation.

Expect acknowledgment within seven days. Fix timing depends on severity and reproducibility. Please allow a reasonable remediation period before public disclosure.

Never include real clipboard contents, credentials, tokens, encryption keys, or other personal data in a report.
